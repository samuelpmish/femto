Examples

Each example is one C++ source file in examples/cpp, also compiled to WebAssembly so it can run on its page.

Hall effect current sensor

2D magnetostatics: a gapped ferrite core reads the current in a wire passing through it and screens out its neighbor.

Parallel-plate capacitor

2D electrostatics: capacitance from the field energy, fringing fields included.

TO-220 regulator on a heatsink

3D heat conduction from a silicon die through the package and heatsink to the air.

Notched fracture specimen

2D finite-deformation elasticity: a notch opened in load steps, solved by Newton's method.

Coffee mug vibration modes

3D modal analysis of a procedurally generated mug.

Induction coil and ferrite core

3D magnetostatics with H(curl) elements on a tetrahedral mesh of copper, ferrite and air.

Lid-driven cavity

2D incompressible Navier-Stokes with Taylor-Hood elements, Newton to the steady state.

Pressure pulse in a disk

2D acoustics against the analytic solution: hard wall, absorbing condition, or a PML ring.
